# Assets Directory

This directory contains assets used by the Language Translator application, such as:

- Icons
- Images
- Fonts
- Other resources

## Required Files

The following files should be placed in this directory:

- `icon.ico` - Application icon (Windows)
- `text_icon.png` - Icon for text translation
- `voice_icon.png` - Icon for voice translation
- `document_icon.png` - Icon for document translation
- `image_icon.png` - Icon for image translation

You can create these icons using any icon creation tool or download free icons from websites like:
- [Flaticon](https://www.flaticon.com/)
- [Icons8](https://icons8.com/)
- [Iconscout](https://iconscout.com/)

Make sure to use icons that are compatible with the application's design and color scheme.
